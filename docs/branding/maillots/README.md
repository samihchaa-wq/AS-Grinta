# Maillots

Sources vectorielles des trois maillots proposés pour un match
(`assets/images/jerseys/`). Ce sont des dessins originaux, faits pour
l'application : aucune marque, aucun écusson, seulement les couleurs des
maillots du club.

Pour modifier un maillot, éditer son SVG puis l'exporter en PNG transparent
de 520 × 600 pixels sous le même nom dans `assets/images/jerseys/`.
