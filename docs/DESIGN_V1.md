# AS Grinta — archive fonctionnelle V1

Ce fichier est conservé uniquement comme repère historique.

**Il ne décrit pas le produit actuel et ne doit pas servir de source de vérité
pour une modification, un audit ou une suppression.**

La V1 précédait plusieurs évolutions importantes, notamment :

- le module de gestion sportive actuel ;
- le Live et ses événements ;
- le rôle `moderateur` ;
- la temporalité J-6 / T-15 ;
- la validation du Live avant le passage en match passé ;
- le vote HDM ancré sur la validation et ouvert 24 h ;
- les règles de notifications actuelles ;
- la suppression du multiplicateur ×2.

Pour comprendre l’état actuel :

1. prendre la production comme référence ;
2. lire `README.md` pour la vue d’ensemble actuelle ;
3. lire `docs/NOTIFICATIONS_V2.md` pour les notifications ;
4. suivre `AGENTS.md` pour les règles d’audit et de nettoyage.

L’historique détaillé de cette ancienne V1 reste disponible dans Git.
